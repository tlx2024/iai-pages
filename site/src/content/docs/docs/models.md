## 个人版官方 AI（规划中）

个人版通过官方账号与积分调用模型。网关只连接已核验的厂商正式 API，模型清单和用量规则由服务端管理。用户不填写上游地址或 API Key。

知识库、检索与 Wiki 编排留在本机；模型请求只包含本次确认的必要内容。OCR 需逐批确认选定页图与预算。价格以正式发布为准，当前不开放自助注册。

## 企业私有部署

企业模型网关可连接企业配置的 Ollama、vLLM、OpenAI 兼容服务或其他已支持的提供方。模型权重与上游凭据由企业运维管理，不随公开个人版安装包分发。

模型文件体积与硬件需求取决于选定模型。内网部署和第三方模型许可由实际交付确认，见[私有部署指南](/docs/deployment/)。
