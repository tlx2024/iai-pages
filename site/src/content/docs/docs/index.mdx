平方和工厂智能中枢（IAI）是面向制造现场的 AI 智能中枢：向下接入 MES、SCADA、ERP、LIMS 等系统，向上给每个岗位一个统一入口，覆盖对话、工作台和智能体中心三种用法。

这里的文档分两条路径：想先体验的，从**试用版**开始；准备在企业内网正式使用的，看**私有部署**。
