试用版是 IAI 唯一公开下载的桌面安装包：在本机运行后端和 SQLite 数据库，自带精选的演示数据，用于评估 IAI 在你所在场景中的价值。

:::note
试用版尚未公开发布。本页按发布计划编写，具体以安装包附带的说明和许可协议为准。
:::

## 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11，64 位 |
| 内存 | 建议 16 GB 及以上 |
| 本机模型（可选） | 建议 8 GB 及以上显存的独立显卡，并安装 Ollama |
| 网络 | 安装与使用都可以离线；只有选择云端模型时才需要联网 |

## 安装与校验

1. 从[下载页](/iai-pages/download/)下载安装包，并用 PowerShell 核对 SHA256：

   ```powershell
   Get-FileHash .\IAI-Trial_<版本>_x64-setup.exe -Algorithm SHA256
   ```

2. 安装包目前没有代码签名，Windows SmartScreen 可能提示“未知发布者”。核对校验和无误后，点击**更多信息 → 仍要运行**。

## 账号

| 账号 | 用途 | 口令 |
|---|---|---|
| 主账号 | 日常使用、审批 | 首次启动时由你设置 |
| 操作员（A 线） | 演示岗位视角 | 每次安装随机生成，登录页点一下自动填入 |
| 设备工程师 | 演示“一人发起、另一人审批” | 同上 |

试用版不能新增账号，也不能修改授权。多用户、组织与资源树授权属于服务器版。

## 模型档位

| 档位 | 说明 | 数据是否出本机 |
|---|---|---|
| 本机模型 | 使用本机 Ollama。首次启动检测到可用模型时自动选用 | 否 |
| 云端模型 | 填写你自己的 OpenAI 兼容接口地址与 API Key | 是，需要你显式同意 |
| 暂不接模型 | 可以浏览知识库、对象、账本和演示案例，不能对话 | 否 |

安装包里不内置任何 API Key。准备方法见[模型准备](/iai-pages/docs/models/)。

## 可以体验什么

- 智能助手：流式对话、意图路由、技能调用、带引用的回答、执行账本；
- 知识库：浏览、带引用的检索、在个人空间导入自己的 Markdown / 文本文档、Wiki 生成；
- 技能：运行内置技能，数据来自内置的模拟平台；
- 智能体中心：起草、编辑、试运行智能体；
- 运行中心与审批：岗位账号发起动作，主账号审批；
- 本体与根因分析：浏览对象，运行内置的演示案例；
- 平台接入：查看内置模拟平台的配置，演示故障注入。

以下能力只在服务器版提供：新增账号与授权、接入真实 MES / SCADA、消息通道、定时与无人值守运行、行业扩展包（医药、研发）、智能体发布与配置包导入导出。完整对照见[部署形态](/iai-pages/deployment/)。

## 数据位置

所有数据只保存在本机：

```text
%APPDATA%\com.industrialai.demo
```

- **重置演示数据**会同时清掉你导入的文档。界面会二次确认，并提供“先导出”。
- **卸载**不会删除数据目录；不再需要时可以手动删除上面的目录。

## 有效期

- 每个试用版构建后 **120 天**内有效，启动页和顶部横幅都会显示到期日；
- 到期后进入**只读**：可以查看，也可以导出个人空间里的文档和报告，但不能再发起新的操作；
- 到[下载页](/iai-pages/download/)下载新版本即可继续试用。
