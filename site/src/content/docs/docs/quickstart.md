本页带你用**试用版**走一遍 IAI 的核心链路。试用版在你自己的 Windows 电脑上运行，自带演示数据，不需要服务器，也不需要接入任何真实系统。

:::note
试用版尚未公开发布，下面的步骤按发布计划编写。发布后请以[下载页](/iai-pages/download/)和安装包内的说明为准。
:::

## 1. 下载并校验

1. 在[下载页](/iai-pages/download/)下载最新的试用版安装包（`IAI-Trial_<版本>_x64-setup.exe`）。
2. 核对 SHA256 校验和，确认文件完整、没有被篡改：

   ```powershell
   Get-FileHash .\IAI-Trial_0.3.0_x64-setup.exe -Algorithm SHA256
   ```

   输出的哈希值应与下载页上的一致。

## 2. 安装

双击安装包按提示安装。安装包目前没有代码签名，Windows 可能弹出“Windows 已保护你的电脑”：点击**更多信息 → 仍要运行**。前提是你已经按上一步核对过校验和。

## 3. 首次启动

- **设置主账号口令**：首次启动时，向导会让你为主账号设置口令。试用版不使用任何公开的默认口令。
- **选择模型档位**：
  - **本机模型**：本机已装 Ollama 并拉取了推荐模型时，自动使用本机模型，数据不出本机；
  - **云端模型**：填写你自己的 API Key（OpenAI 兼容接口），需要你显式同意数据出网；
  - **暂不接模型**：可以浏览知识库、对象、账本和演示案例，但不能对话。

  准备方法见[模型准备](/iai-pages/docs/models/)。

## 4. 走一遍核心链路

用演示数据依次体验下面几个环节，大约十五分钟：

| 环节 | 在哪里 | 看什么 |
|---|---|---|
| 提问 | 智能助手 | 用现场的说法问一个问题，例如“A 线今天的生产情况怎么样？” |
| 依据 | 回答里的引用 | 点开引用，看知识库原文、版本和审核状态 |
| 风险与审批 | 智能助手 → 审批中心 | 发起一个会改动现场的动作（例如复检），看它如何生成审批卡；切换到另一个岗位账号批准 |
| 执行账本 | 运行中心 | 查看刚才这次处置的每一步：调用了什么技能、参数和返回 |
| 根因分析 | 本体与对象 → RCA | 打开内置的温升异常案例，看候选原因和正反证据 |
| 知识库 | 知识库 → 个人空间 | 导入一份自己的 Markdown 或文本文档，再对它提问 |
