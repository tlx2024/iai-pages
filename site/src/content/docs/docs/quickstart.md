本指南带您了解 IAI 智能工厂中枢的核心工作链路：统一系统接入、权威本体对齐、智能助手查询、风险审批与不可变执行账本。

## 1. 系统接入与环境核验

1. 确认中枢服务各基础容器（PostgreSQL 16、pgvector、Redis、MinIO、Web 工作台）已通过 `docker-compose up -d` 启动并在内网监听；
2. 运行环境连通性检查脚本验证数据库连接、向量扩展与模型端点响应；
3. 打开内网浏览器访问 Web 工作台端口，以管理员身份登录并完成初始组织与岗位初始化。

## 2. 体验核心业务链路

通过系统内置的制造演示数据集，您可以依次体验以下环节：

| 环节 | 入口模块 | 核心操作与关注点 |
|---|---|---|
| **现场提问** | 智能助手 | 使用一线现场口吻提问（例如“A03 压片机当前的温升情况与近三小时报警”），观察语义意图解析与技能调用 |
| **事实出处** | 引用来源 | 点击回答结论中的出处角标，定位到具体的知识文档、规程条款、版本与审核记录 |
| **动作审批** | 审批中心 | 发起涉及现场动作的高风险指令（如设备参数调整或复检），系统自动挂起并生成审批卡，由责任工程师签字放行 |
| **执行账本** | 运行中心 | 查看每次处置的不可变执行账本：调用了什么技能、下发了什么参数、外部系统返回了什么回执 |
| **根因排查** | 智能体中心 | 观察深夜或异常报警发生时，自动化排查智能体如何收集多源证据并形成结论待早班确认 |
