title: 常见问题
description: 关于 IAI 试用版与服务器版的常见问题。
---

## 试用版收费吗？

试用版免费下载，供评估使用。具体使用条款以安装时展示的许可协议为准。

## 试用版需要联网吗？

不需要。安装和使用都可以离线。只有你选择“云端模型”时，对话内容才会发送到你指定的模型服务商，而且需要你先显式同意。

## 我的数据会被上传吗？

试用版的数据只保存在本机的数据目录里（见[试用版指南](/iai-pages/docs/trial/#数据位置)）。服务器版部署在企业内网，数据留在企业自己的服务器上；如果全部使用本机模型，数据不会离开工厂。

## 为什么 Windows 提示“未知发布者”？

安装包目前还没有代码签名，Windows SmartScreen 会提示风险。请先在[下载页](/iai-pages/download/)核对 SHA256 校验和，确认无误后点击**更多信息 → 仍要运行**。代码签名正在推进中，完成后会在更新日志里说明。

## 试用版到期后怎么办？

到期后进入只读模式，仍然可以查看和导出你的文档与报告。到[下载页](/iai-pages/download/)下载新版本即可继续试用。

## 试用版能接我们的 MES / SCADA 吗？

不能。试用版只提供内置的模拟平台，用于演示接入方式和故障注入。接入真实系统是服务器版的能力，也是为了防止试用版被当作生产网关使用。

## 有 macOS 或 Linux 版吗？

试用版目前只提供 Windows x64 安装包。服务器版运行在 Linux 服务器上，通过浏览器或 Windows 企业客户端使用。

## 支持哪些模型？

服务器版的 AI 网关支持 OpenAI 兼容接口、Anthropic、Ollama 和 vLLM 四类模型；试用版支持本机 Ollama 和 OpenAI 兼容的云端接口。详见[模型准备](/iai-pages/docs/models/)。

## 没有外网的工厂能部署吗？

可以。镜像包可以通过离线介质交付，模型权重在外网下载后离线拷入，全部使用本机模型运行。

## 功能页上的“工程验证中”是什么意思？

表示功能已经实现、自动化回归测试通过，但还没有经过真实现场的验收。“规划中”表示尚未实现，不代表交付承诺。
